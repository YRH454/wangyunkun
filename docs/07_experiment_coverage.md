# 7. 实验关注点与方案对照

这份表将审查中与**数据和实验**相关的关注点归纳到本项目的工作项，不逐字转载审稿意见，也不代表任何问题已经解决。这里只覆盖用户优先要求的数据和实验；论文行文、文献与其他章节另行处理。

部分本项目独立代码已实现并通过合成测试；**实际数据、历史记录或新实验仍待核实／完成**。原论文的真实设置、旧结果和本项目拟定设置必须分开，不能用建议值填补原作者记录。各功能范围见[实现说明](09_training_implementation.md)。

|---|---|---|---|
| 原始数据如何构建 | 登记文本来源、配对与负例生成、标注规则、类别分布和数据版本 | [数据与划分](01_data_and_splits.md) | 原始来源、标注及配对记录；无法追溯时写未知 |
| 划分与信息泄漏 | 逐对、倒序和单句审计；增加近重复及来源复核；必要时建立句子分组新划分 | [数据与划分](01_data_and_splits.md) | 真实来源ID、近重复人工裁定及不覆盖原文件的划分记录 |

| 参数量与CPU效率 | 计数口径、硬件、线程、批量、预热、重复、分词范围、延迟分布和内存分开记录 | [服务器与环境](05_windows_environment.md) | 同条件的真实测量；不能仅由参数或FLOPs解释速度 |
| 公开与部署边界 | 先确认代码、数据和模型各自许可；部署结论限于实际测试设备 | [检查清单](06_checklist.md) | 授权及目标设备验证；未授权材料保持本地 |

原始审查材料、论文和本地逐条审计结果不在公开仓库中。若需要逐条回溯到具体评论及稿件位置，应在本地使用已有工作单，并在有权共享时再决定公开范围。工作单中有关“尚未发现数据”等说明反映其编写时的状态，当前数据与审计情况应以新记录为准。
