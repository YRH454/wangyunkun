# 3. 基线、消融与实验矩阵

论文的实验范围和结果以论文正文为准；下面同时列出仓库独立实现的运行选项。代码和合成测试不是历史运行记录，见[实现说明](09_training_implementation.md)。模型候选与检查点见 [`models.json`](../configs/models.json)，运行矩阵见 [`experiment_matrix.json`](../configs/experiment_matrix.json)。

## 3.1 基线分层

| 类型 | 方法 | 训练信息 | 主要用途 |
|---|---|---|---|
| 同骨干监督 | ESIM/BiLSTM + CE | L | 主要公平参照 |
| 同骨干监督 | ESIM/BiLSTM + CE+SCL | L | 检查监督对比部分 |
| 同骨干半监督 | 自训练 | 相同L与U | 伪标签路线 |
| 同骨干半监督 | 一致性训练 | 相同L与U | 预测一致性路线 |
| 本项目方法 | 两阶段 pair-level 对比 | 相同L与U | 独立实现，非官方实现 |
| 预训练监督 | 中文 BERT-base | L + 公开预训练知识 | 常规预训练参照 |
| 轻量预训练监督 | 中文小型 RoBERTa 候选 | L + 公开预训练知识 | 参数、资源及预测权衡 |
| 可选补充 | 中文 RoBERTa-wwm-ext | L + 公开预训练知识 | 更强预训练监督参照 |
| 可选半监督 | Mean Teacher | 相同L与U | EMA教师一致性路线 |
| 可选自监督 | 文本对 dropout 对比预训练 | 相同U后用L | 视图对比预训练路线 |
| 可选领域适配 | BERT继续掩蔽语言模型训练 | 原有预训练知识 + 相同U + L | U领域继续预训练路线 |

候选 checkpoint 的仓库ID和某次核对到的 revision 固定在配置中；`uer/chinese_roberta_L-4_H-512` 的 API 元数据没有给出许可字段，**使用前需核实许可及权重来源**。模型仓库与原始训练语料可能涉及独立条款。预训练模型对公开基准的潜在预训练污染若无法验证，应报告不确定性；不能把它描述成和从零训练完全相同的训练信息。

论文将 DeepSeek-V3.2 作为零样本 API 参考：每对句子独立查询，不使用上下文示例；五次重复为 API 调用重复而非本地训练种子，也不分配 LDP 或本地训练预算。t-SNE 中的其他模型展示历史分析结果，不因此等同于仓库中已有其训练实现。

## 3.2 分阶段执行，避免一开始就运行千余次

| 档位 | 数据 × LDP × 种子 × 方法 | 报告用途 |
|---|---|---|
| Smoke | 1 × 1 × 1 × 2 = 2 次 | 检查流程；结果不得用于正式比较 |
| Core | 2 × 3 × 5 × 6 = 180 次 | 完成授权、数据门槛及调参后，进行资源可控的首批比较 |
| Full | 4 × 9 × 5 × 7 = 1,260 次 | 扩展矩阵；由实际资源与研究需要决定 |

上表是独立代码的可选执行矩阵，并非论文已经运行的组合；只计每个组合一次训练，不包括调参、消融、失败重试和资源测量。论文在各公共数据集使用指定标注样本数，而非将农业数据的全部九档LDP逐一套用到公共数据集。论文明确的调参候选为CE 9组、BERT-base和四层RoBERTa各6组，见[训练协议](02_training_protocol.md)。

可选扩展为2个数据集 × 3个LDP × 5个种子 × 3种方法 = 90次，调参另计。默认不自动执行，也不以省略某一条路线替代对公平性和研究边界的说明。

## 3.3 消融：分别回答什么

论文在农业数据30% LDP上报告A0—A6和A8，使用五个训练种子；未标注数据规模另报告25%、50%和100%。以下说明配置，不替代论文中已有的结果：

| ID | 阶段1 → 阶段2 | 差异／可回答问题 |
|---|---|---|
| A0 | 单阶段 CE | 同骨干监督对照 |
| A1 | 单阶段 CE+SCL | 与A0比较加入SCL |
| A2 | CE → CE+UL | 无SCL情况下加入U及其一致性目标 |
| A3 | CE+SCL → CE+UL | 完整配置；与A2比较第一阶段SCL |
| A4 | CE+SCL+UL 单阶段 | 联合目标配置；与A3比较的是整个联合／分阶段配置，而不只是顺序 |
| A5 | CE+SCL → CE+UL，仅用L的增强视图 | 额外U和掩蔽视图目标的差异；记录重复L的曝光数 |
| A6 | CE+SCL → CE+UL，随机掩蔽 | 与A3比较术语保护；候选范围及掩蔽数／强度应可比 |
| A7 | CE+SCL → CE+UL，U规模为25% / 50% / 100% | 不同U规模；记录替换采样与有效曝光次数 |
| A8 | CE+UL → CE+SCL | 反转阶段顺序；与A3尽量匹配各目标的实际更新、L/U曝光和优化器重置 |

双阶段配置在阶段边界恢复第一阶段最优权重并重置优化器；A0和A1为单阶段配置。A4同时使用三个目标且只有一个阶段，因目标共现与优化状态不同，不能单独证明“顺序”的因果作用。

农业术语词表已包含119项；需要术语保护的条件通过 `--term-lexicon` 指向该文件。复用运行的前提是数据ID、训练规则、轮数、超参数及种子完全一致。

## 3.4 其它需要补充的实验与记录

- 公开数据集注明版本、语言、实际样本量和官方／重划分状态；统计128 token／字符截断率，必要时在不看测试集的条件下另行预注册更长输入对照。
- 对每个训练阶段保留训练和验证loss、accuracy、macro-F1、选中步骤及停止点；记录错误样本分析的抽样规则，原文留本地。
- 对标签不均衡数据展示混淆矩阵和逐类 P/R/F1，核对二分类F1与macro-F1计算口径；不能只展示准确率。
- 论文的掩蔽敏感性图展示测试集扫描：概率为0.05、0.10、0.15、0.20、0.25、0.30；测试扫描最高点不作为验证集选参。句长使用截断前两句原文字符数之和。t-SNE只作可视化，记录输入层、抽样、降维参数与随机种子。
- 计算模型参数、文件大小、FLOPs、CPU延迟、进程峰值内存和GPU显存时要区分测量单位和统计范围，具体方案见环境文档。
- Mean Teacher、文本对 dropout 对比预训练和BERT领域继续预训练的建议参数见 [baseline_protocols.json](../configs/baseline_protocols.json)。其中 dropout 文本对方法只借鉴 SimCSE 类视图思路，不冒充官方 SimCSE；BERT的掩蔽语言模型只使用审计后的训练U并隐藏标签。
