# 6. 检查清单与待确认事项

每一项都需以数据文件、权限、代码、日志或真实结果为依据；本清单不是原作者的回复信。

## 6.1 训练前门槛

- [ ] 确认农业候选数据及生成数据的使用权限、来源、标注方式与可共享范围；确认各公开基准和预训练模型的许可。
- [ ] 对选定文件做聚合精确审计；确认文本对倒序是否等价，并人工复核规范化冲突。
- [ ] 固定研究问题：官方划分对照或新建句子分组划分；记录 source_id 是否存在、数据哈希与脚本版本。
- [ ] 处理或说明跨划分重复、单句复用、近重复候选、标签冲突和监督子集版本差异；不覆盖原始文件。
- [ ] 分清外部U与剩余训练数据去标签U；确认验证／测试没有进入U，且U标签不会到达训练器。
- [ ] 词表仅拟合训练数据；核对 `<pad>/<unk>/<mask>`、截断和tokenizer版本。
- [ ] 取得或独立构建有出处、可使用的农业术语词表；锁定版本及匹配单位。未知时保护掩蔽条件不启动。
- [ ] 审核现有独立训练器及其合成测试；在正式运行前确认CE、监督／无监督对比分母、批内负例、缺正例与微批变化符合本项目预先登记的公式。已实现不等于已完成科学验证。
- [ ] 在真实目标设备上检查GPU、驱动、PyTorch/CUDA、可用显存；先跑不形成比较结论的smoke。

## 6.2 公平性与可复核性

- [ ] 预先锁定数据版本、LDP、同种子L/U样本、模型候选、6次调参预算、选择指标及停止规则。
- [ ] 明确监督模型、半监督模型和外部预训练模型可使用的不同信息，不把它们称为完全同一信息条件。
- [ ] 记录每个方法实际L/U／增强视图曝光、优化器步数、训练时长、显存和checkpoint选择。
- [ ] 拟定消融对照时匹配阶段边界、权重、实际步数与掩蔽强度；对于不能匹配的因素明确保留混杂解释。
- [ ] 对公开基准核对官方版本；新划分与官方划分分开报告。不能只引用某一论文的数字充当同条件实测。
- [ ] 固定预测阈值、各类和macro指标实现；从每次预测计算F1，再汇总五种子。
- [ ] 统计中区分跨seed、跨LDP和测试样本不确定性；配对及多重检验在看测试结果前写明。
- [ ] CPU／GPU效率测量明确输入、线程、预热、重复次数、端到端或模型本体范围和实际设备。
- [ ] 完成错误案例、句长数量与置信区间、训练／验证曲线和掩蔽敏感性，数据和原文留本地。
