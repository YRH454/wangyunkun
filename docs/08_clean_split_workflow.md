# 8. 防泄漏划分与标注比例采样

这里的代码只为**有权本地处理的数据**建立新版本，不训练模型，也不上传数据。合并旧训练、验证、测试文件后重新分组，旧测试记录可能被分到训练，因此结果不是原论文或官方基准的测试结果，不能与其数字作为完全相同协议比较。运行前固定输入文件、阈值和种子，不得依据测试性能反复选择划分。

## 8.1 程序实际处理的风险

1. 只读入 JSON Lines 的 `sentence1`、`sentence2`、`gold_label`；标签为0、1或-1。文本采用 NFKC 加去除 Unicode 空白检查，原文保留在输出中。当前文本匹配按**对称任务**处理：倒序文本对视为同一对；如果任务有方向性，不应直接使用此代码。
2. 相同规范化无序文本对去重；同一对同时出现0和1时，将该对的**所有标注记录**隔离到 `quarantined_conflicts.jsonl`，不选择或改写标签。文件保留输入文件序号和行号供本地人工复核。
3. 句子作为图节点，每个已标注文本对将两句连接；同一句及相近句子通过连通分量分组后，组整体进入训练、验证或测试。若启用来源ID，相同来源也连接到同一组。
4. 这里的“相近”是一个预先规定的**表面规则**：规范化后句子的去重字符二元组集合 Jaccard 相似度 ≥90%。使用完整的前缀筛选和精确计算处理该指标，不是概率式近邻采样；这仍不能识别所有同义改写，也可能将内容不同但表面相似的句子分组。单字符句子用其自身作为特征。
5. 目标是80%/10%/10%，按分组贪心近似分配并兼顾0/1类别比例。默认每个划分的实际比例与目标差不超过全部样本的2个百分点，正类占比与总体相差不超过5个百分点，且每个划分包含两类；不满足时停止，不强拆组。报告实际数量和比例，不保证优化过程全局最优。
6. 外部无标签池删除与任何标注对重复的无序对、冲突对，以及与验证／测试句子完全相同或满足上述近重复规则的记录；提供完整来源ID时也排除共同来源。无标签输出不含 `gold_label`。
7. 保留输入和输出 SHA-256、程序文件哈希、Python版本、种子、隔离数及各划分统计。再由另一程序重新读取输出，检查哈希、字段、精确重叠、所选表面近重复和可用来源ID；复核与生成脚本共享归一化和相似度工具，并非完全独立实现。前缀筛选在合成数据测试中与穷举结果比较。

**未解决的边界：** 语义近重复、生成器预训练／微调语料是否接触过测试文本、来源ID缺失时的来源级独立性、许可及跨数据集迁移污染均不能由此证明。冲突隔离也不能替代人工判断。词表及可学习预处理只能在新的训练数据上拟合。

## 8.2 生成和验证农业候选新版本

以下例子中的路径是示例，请改成有权使用的本机数据根目录。只指定 `train_50.txt`、`dev.txt` 和 `test.txt`；不要同时传入重复的 `train_sup_50.txt`。不使用未核实的替代测试文件。输出目录必须不存在；命令失败或没有 `manifest.json` 的目录不能当作完整数据使用。

```powershell
$datasetRoot = 'D:\path\to\local\data'
$agriRoot = Join-Path $datasetRoot 'Agriculture9_S'
python -B scripts/prepare_clean_split.py `
  --inputs (Join-Path $agriRoot 'train_50.txt') `
           (Join-Path $agriRoot 'dev.txt') `
           (Join-Path $agriRoot 'test.txt') `
  --output-dir 'data\agri_clean' `
  --seed 20261030 --lexical-similarity-percent 90

python -B scripts/verify_clean_split.py `
  --split-dir 'data\agri_clean' `
  --output 'reports\agri_clean_verification.json'
```

复核状态 `EXACT_AND_CHOSEN_LEXICAL_CHECKS_PASS` 只表示上述约定的检查通过，不等于不存在其他数据泄漏。如果数据有完整的来源字段，可在**所有输入记录**中提供同一字段并加 `--source-field source_id`；值必须是非空字符串，或包含所有相关来源ID的非空字符串列表。若一对句子对应两个来源，必须提供两个；脚本不能发现来源字段本身是否完整或真实。字段缺失会停止，而不是悄悄降级为来源独立。

| 本地输出 | 内容 |
|---|---|
| `train.jsonl` / `validation.jsonl` / `test.jsonl` | 新划分的去重标注样本，包含本地样本ID和真实标签 |
| `unlabeled.jsonl` | 已按评估集过滤的外部U，不含监督标签；如果输入没有-1记录则为空 |
| `quarantined_conflicts.jsonl` | 同对标签冲突的原始观测，供本地人工复核，不参加训练或评价 |
| `manifest.json` | 数据、代码哈希及聚合统计；最后写出，缺失表示过程未完成 |

样本内容、ID、隔离文件、哈希清单和审计报告均只放本地；仓库的 `data/` 和 `reports/` 已被忽略，但每次提交前仍须检查。不得覆盖原始文件，也不要把这些派生数据用于无授权的分享或训练。

## 8.3 较低表面相似度的人工复核候选

通过上述复核后，可进一步列出训练／无标签与评估集、以及验证与测试之间，字符二元组Jaccard相似度在80%（含）到90%（不含）的句子候选。这个区间只是本项目的复核起点，**不是语义等价判定**；候选可能不泄漏，也会漏掉同义改写。程序不改变数据划分或标注，每条候选初始状态为 `PENDING_HUMAN_REVIEW`：

```powershell
python -B scripts/review_near_candidates.py `
  --split-dir 'data\agri_clean' `
  --output-dir 'reports\agri_near_review' `
  --minimum-percent 80 --max-rows 5000
```

`review_candidates.jsonl` 含原句和本地样本ID，`summary.json` 给出总候选数和保存数。候选按确定性顺序截断而非随机抽样；如果 `truncated=true`，不可把保存的部分当作全部或无偏样本。请结合对应文本对和来源由熟悉领域的人判断，保留复核依据；确认为泄漏的候选应在查看模型测试结果之前重新制定并执行分组／剔除规则，生成新版本并再次复核。该脚本本身不会把人工决定应用到划分中，也无法证明所有语义近重复已被发现。

## 8.4 九档标注比例与无标签模式

在复核通过的新训练池上，每个类别按种子固定打乱，再取前缀；各类别数量采用四舍五入到整数（正数半数向上），因此实际总数可能与目标比例差一两条。相同种子的10%、15%……50%是嵌套子集。每次生成前程序重新验证父划分并检查文件哈希；相同条件下所有比较模型应使用同一份L/U样本ID。

农业候选使用已过滤的外部U：

```powershell
python -B scripts/create_ldp_subset.py `
  --split-dir 'data\agri_clean' `
  --output-dir 'data\agri_ldp30_seed11' `
  --percent 30 --seed 11 --unlabeled-mode external
```

公共基准若没有外部U，可将新训练池中**未选中的标注样本去掉标签**后作为U；该模式与外部U不是同一种训练信息条件。`--unlabeled-mode remaining` 使用这种方式，最多选15,000条；`external` 使用父划分里的外部U，若为空则停止。U文件没有 `gold_label`；训练集或采样器不得另行读取U的隐藏真值。每个LDP结果包含 `train_labeled.jsonl`、`train_unlabeled.jsonl` 和记录实际数量的 `manifest.json`；验证／测试仍使用父划分的文件。

可选比例为10、15、20、25、30、35、40、45、50；正式报告种子为11、23、37、47、59。每种子和比例使用一个新的输出目录；无需因结果不好改种子或重划测试集。可调 `--unlabeled-cap`，更改后必须在比较中统一并报告。

## 8.5 其他基准与失败处理

AFQMC、PAWS-X、LCQMC可传各自的 `train.txt`、`dev.txt`、`test.txt`，但重新合并后只属于各自的新分组版本；官方分组或官方指标需另行保留和核实，不能冒称官方基准复现。不同数据集不应共享一个输出目录。

默认 `--candidate-limit 5000000` 是防止极端候选集合导致长时间运行的安全上限；达到上限会停止，不会给出“检查通过”。如果分组无法满足比例或类别约束，报告原因并重新审视数据或协议，不要拆散相同／近重复组来强行满足比例。程序不会覆盖已存在目录；若写入过程中断，请保留现场并使用全新目录重试。
