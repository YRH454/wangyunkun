# 2. 训练协议与公平性

本文件整理论文描述的训练协议和独立实现的使用方式；对应机器可读配置见 [`protocol.json`](../configs/protocol.json)。仓库代码依据论文与材料独立整理，不是历史运行代码。真实训练使用已授权、经复核并锁定的数据；仓库提供 [119 项农业术语词表](../data/agriculture_sentence_clean_v3/agricultural_terms.txt)。

## 2.1 比较对象与可比条件

同一项比较应共享任务定义、训练／验证／测试ID、类别标签、LDP、训练种子、评价代码与模型选择规则。所有使用无标签目标的方法还共享U的来源、实际ID和数量；U的标签在任何模型调用前删除。监督方法的训练目标只使用L；预训练模型和无标签方法使用的额外信息应分别说明。

预训练编码器和从随机初始化开始的BiLSTM曾接触不同的预训练信息，也应分组报告，不能将差异都归因于模型结构。每个模型允许使用适合其架构的预处理和学习率，但必须报告截断比例、实际样本曝光、总更新数、训练时长、显存以及超参数搜索预算；不能用同一个学习率来代替公平调参。

农业数据每档标注子集按采样种子11分层抽取，九档嵌套；同一档下各方法和五个训练种子使用同一标注子集与评估集。数据预处理只拟合训练部分，不使用验证集或测试集构造词表。

## 2.2 论文的基础训练预算

| 项目 | 训练规则 |
|---|---|
| 采样与训练种子 | 农业子集采样为11；独立训练种子为11、23、37、47、59；调参训练种子为101 |
| 模型选择 | 检查点取验证集 macro-F1 最大值、平分选最早；早停计数使用相对上一次显著改善至少超过 0.0001 的规则 |
| 停止 | 每轮结束验证；连续4轮未达到最小改善幅度则停止 |
| 上限 | 单阶段最多32轮；双阶段各最多16轮；实际停止轮次均记录 |
| 优化器／调度 | AdamW；每阶段线性预热前10%计划更新，再线性衰减；梯度范数裁剪1.0 |
| 阶段切换 | 恢复第一阶段验证集最优权重，重置优化器和调度器；阶段一已经实际执行过的更新都计入物理训练成本，即使权重后来回退 |
| 精度／设备 | 默认 FP32，Windows DataLoader workers=0，同一GPU一次只跑一个模型；必须记录实际环境 |
| 批量 | BiLSTM每个微批16个L、累积2次；Transformer每个微批8个L、累积4次；均为每次更新32个L。每轮重新打乱，不足一次完整更新的尾部不参与该轮训练 |
| 加入U的方法 | BiLSTM每微批额外16个U；原始与增强视图各一次前向。U与监督批的开销额外计入，不能宣称计算预算相同 |
| 截断 | 初始上限128：BiLSTM为分字后的单位，Transformer为自身tokenizer token（含特殊token）；记录各模型在各划分的截断率与原文覆盖率 |
| 决策 | 二分类概率阈值0.5固定；不得用测试集选择阈值、早停点、样本或实验 |

GPU 显存不足时，减小微批并调整累积会改变单个微批内的对比负样本，因此应作为新配置记录，不能称为数值等价。不同模型的实际训练轮次仍可能因早停而不同；相同上限不等于相同实际计算量。

## 2.3 调参而不看测试集

论文采用调参训练种子101，以验证集 macro-F1 选择；农业数据的标注子集采样种子仍为11。明确列出的学习率与有效批量候选为：

- CE：学习率 `1e-3, 5e-4, 1e-4`，有效批量 `16, 32, 64`，共9组。
- 中文 BERT-base：学习率 `1e-5, 2e-5, 3e-5`，有效批量 `16, 32`，共6组。
- 四层中文 RoBERTa：学习率 `3e-5, 5e-5, 1e-4`，有效批量 `16, 32`，共6组。

论文报告这三类模型选中的学习率分别为 `5e-4`、`2e-5`、`5e-5`，有效批量均为32。自训练阈值候选为 `0.90, 0.95, 0.99`，一致性方法为 `0.90, 0.95`，两者选中值均为0.95。公开数据集各自在本数据集验证集调参；各候选运行采用32轮预算及相同早停规则。其他方法不套用未经论文列明的候选网格。

## 2.4 两阶段 pair-level 对比

同一文本对进入交互式 BiLSTM 编码器；按字符切分，词表由选中的L和可用U训练文本建立，包含 `<pad>`、`<unk>`、`<mask>`，不使用验证／测试文本；嵌入维度300，按均值0、标准差0.1的正态分布初始化并参与训练。上下文编码和交互组合各一层双向LSTM，方向隐藏维度256，dropout 0.5。分类输出为两个logit；标注匹配类别为1。本仓库为独立实现，不是历史训练运行代码。

设当前监督微批表示为 $z_i$、标签为 $y_i$，$P(i)=\{p:p\ne i, y_p=y_i\}$，只对 $|P(i)|>0$ 的锚点求平均：

```text
L_sup = mean_i [ -(1 / |P(i)|) * sum_{p in P(i)}
                  log( exp(cos(z_i,z_p)/tau) /
                       sum_{a != i} exp(cos(z_i,z_a)/tau) ) ]
```

该定义将其他标签样本放入分母；温度 `tau=0.07`，在微批内计算。无正例锚点跳过；若整个微批无有效锚点，该步SCL为零并记录计数，不得除零。同标签文本对共享分类标签，不代表它们是同一农业问题或语义等价。

本实现默认第一阶段 `L1 = CE(L) + 0.5 * L_sup(L)`，第二阶段 `L2 = CE(L) + 0.5 * L_unsup(U)`；两个CE均按实际标注微批求平均，第二阶段继续更新编码器和分类器。无监督项由一对原始表示与掩蔽视图构成，微批大小B不小于2：

```text
L_unsup = mean_i [ -log( exp(cos(z_i, z_aug_i)/tau) /
                          sum_j exp(cos(z_i, z_aug_j)/tau) ) ]
```

分母是本微批的增强视图，含自身正例；不是对全部无标签集同时求和。其他经规范化后相同的文本对不能当作负例：训练前去除重复或在相似度矩阵内屏蔽它们。无法识别的语义近义假负例仍是局限；不借助隐藏标签声称全部消除。

掩蔽规则：先在每条原文中匹配术语词表，把所有匹配术语跨度内的字符位置标记为受保护；取两句共有的字符类型，只要某类型在任一受保护位置出现过，就从候选类型中排除。随机选 `floor(p × 候选类型数 + 0.5)` 个类型，将这些类型在两句中的所有出现位置替换为 `<mask>`。实验工作簿的 A3 调参记录给出验证集选定 `p=0.20`；论文敏感性图则在测试集展示不同概率，测试扫描最高点不作为验证集选值。候选为空或增强后没有变化的样本不进入UL；有效无标签微批不足2对时跳过该UL项。

农业术语表的119项来自现有实验数据工作簿，分别覆盖作物20、病害39、虫害15、农事操作25、投入品20项。随机掩蔽和术语保护掩蔽比较时应记录实际掩蔽情况。

## 2.5 半监督对照的最低实现规范

- **自训练**：先以相同L训练CE模型，使用冻结的最优第一阶段checkpoint对相同U生成一次概率，固定阈值0.95；只接收高置信伪标签，在第二阶段与L一起训练。记录接收比例、类别分布、每阶段更新和额外计算，不读取U隐藏标签。
- **一致性对照**：第一阶段同样用L训练；第二阶段将原文作为弱视图，以相同的强掩蔽规则构造增强视图，停止梯度的弱视图预测仅在置信度≥0.95时提供伪标签，对强视图计算一致性CE，建议权重0.5。明确这只是拟实现的 FixMatch-style 对照，不等同于官方实现。
- **监督Transformer**：使用各自的预训练checkpoint和tokenizer，仅用同一L微调，0.5阈值，验证集选择。模型版本和预训练知识来源另行记录。

所有对照的阶段时长上限、搜索次数和选择原则按本协议登记；实际计算量／预训练开销单列。若方法无法使用某项设置，说明原因并保留可复核的替代协议，不制造“完全等价”的假象。
