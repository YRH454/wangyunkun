# 2. 训练协议与公平性

本文件是**拟定配置**，不是任何既有运行的记录。对应机器可读配置在 [`protocol.json`](../configs/protocol.json)。开始训练前必须确认数据授权、锁定数据版本和拆分、通过对应审计门槛、确定并实现模型及术语词表；当前仓库尚无训练器。

## 2.1 比较对象与可比条件

同一项比较应共享任务定义、训练／验证／测试ID、类别标签、LDP、随机种子、评价代码与模型选择规则。所有使用无标签数据的方法还共享U的来源、实际ID和数量；U的标签在任何模型调用前删除。监督方法不接触U，因此它与半监督方法是**不同训练信息量**的比较，需要如实标明；自训练、一致性和本项目两阶段方法之间才是同一L/U条件的直接比较。

预训练编码器和从随机初始化开始的BiLSTM曾接触不同的预训练信息，也应分组报告，不能将差异都归因于模型结构。每个模型允许使用适合其架构的预处理和学习率，但必须报告截断比例、实际样本曝光、总更新数、训练时长、显存以及超参数搜索预算；不能用同一个学习率来代替公平调参。

建议先固定一个数据版本；对同一数据集和种子，每档标注ID对所有方法一致，九档在该种子内嵌套。每个模型的数据预处理只拟合训练部分。允许有仅供历史复现的另一套旧文件，但不得将其与新的清洁划分混在一个结果表里。

## 2.2 预注册的基础预算

| 项目 | 建议值／规则 |
|---|---|
| 独立报告种子 | 11、23、37、47、59；数据抽样、初始化和训练均记录种子及库版本 |
| 模型选择 | 验证集 macro-F1 最大；最小改进量 0.0001；平分时选最早步骤 |
| 停止 | 每200个优化器更新做一次验证；连续4次未改善则停止；阶段末还要验证一次 |
| 上限 | 单阶段最多4,000次优化器更新；双阶段各最多2,000次；实际停止数均记录 |
| 优化器／调度 | AdamW；每阶段线性预热前10%计划更新，再线性衰减；梯度范数裁剪1.0 |
| 阶段切换 | 恢复第一阶段验证集最优权重，重置优化器和调度器；阶段一已经实际执行过的更新都计入物理训练成本，即使权重后来回退 |
| 精度／设备 | 默认 FP32，Windows DataLoader workers=0，同一GPU一次只跑一个模型；必须记录实际环境 |
| 批量 | BiLSTM每个微批16个L、累积2次；Transformer每个微批8个L、累积4次；均为每次更新32个L |
| 加入U的方法 | BiLSTM每微批额外16个U；原始与增强视图各一次前向。U与监督批的开销额外计入，不能宣称计算预算相同 |
| 截断 | 初始上限128：BiLSTM为分字后的单位，Transformer为自身tokenizer token（含特殊token）；记录各模型在各划分的截断率与原文覆盖率 |
| 决策 | 二分类概率阈值0.5固定；不得用测试集选择阈值、早停点、样本或实验 |

GPU 显存不足时，先减小微批并调整累积以尽量保持每次更新标注样本数；但监督／无监督对比的负样本来自**单个微批**，微批变化会改变损失，必须作为新的配置重新登记、比较并报告，不能称为数值等价。模型变体的实际训练步数仍可能因早停不同：本配置是相同**上限**，不是同等的实际计算量。贡献消融采用固定匹配步数的补充控制，详见下一节。

## 2.3 调参而不看测试集

每个数据集、方法限定6个候选，使用相同参考LDP 30%和专用调参种子101；它与报告的五个种子不重叠。候选为3个学习率乘2个weight decay：

- BiLSTM：学习率 `1e-4, 3e-4, 1e-3`；weight decay `0, 0.01`。
- Transformer：学习率 `1e-5, 2e-5, 3e-5`；weight decay `0, 0.01`。

序列上限固定128，不把长度额外加入这6次搜索；类别损失、增强和对比参数用下面预设值。以验证 macro-F1 选定后，在该数据集对应方法上冻结，覆盖其余LDP和五个报告种子；记录每个候选的配置、预算与验证结果。早停使用相同规则。若个别架构不能按原计划搜索，报告实际试验数；不得因为某个基线结果低而跳过必要调参，亦不得在看过测试结果后临时扩展搜索。

## 2.4 建议实现：两阶段 pair-level 对比

同一文本对进入交互式 BiLSTM 编码器；输入级别按字符切分，词表仅拟合训练文本，包含 `<pad>`、`<unk>`、`<mask>`；嵌入维度300、随机初始化且可训练。上下文编码和交互组合各一层双向LSTM，方向隐藏维度256，dropout 0.5。分类输出为两个logit；标注匹配类别为1。与原论文或现有代码是否完全一致，须独立核实，不在此声称一致。

设当前监督微批表示为 $z_i$、标签为 $y_i$，$P(i)=\{p:p\ne i, y_p=y_i\}$，只对 $|P(i)|>0$ 的锚点求平均：

```text
L_sup = mean_i [ -(1 / |P(i)|) * sum_{p in P(i)}
                  log( exp(cos(z_i,z_p)/tau) /
                       sum_{a != i} exp(cos(z_i,z_a)/tau) ) ]
```

该定义将其他标签样本放入分母；温度 `tau=0.05`，在微批内计算。无正例锚点跳过；若整个微批无有效锚点，该步SCL为零并记录计数，不得除零。建议有种子地构造每类至少两个不同样本的微批，并记录采样与重复曝光；不能把同一个重复样本误当作独立正例。同标签文本对共享分类标签，不代表它们是同一农业问题或语义等价。

第一阶段：`L1 = CE(L) + 0.5 * L_sup(L)`。第二阶段：`L2 = CE(L) + 0.5 * L_unsup(U)`；两个CE均按实际标注微批求平均，第二阶段继续更新编码器和分类器。要实现的无监督候选为一对原始表示与掩蔽视图，微批大小B不小于2：

```text
L_unsup = mean_i [ -log( exp(cos(z_i, z_aug_i)/tau) /
                          sum_j exp(cos(z_i, z_aug_j)/tau) ) ]
```

分母是本微批的增强视图，含自身正例；不是对全部无标签集同时求和。其他经规范化后相同的文本对不能当作负例：训练前去除重复或在相似度矩阵内屏蔽它们。无法识别的语义近义假负例仍是局限；不借助隐藏标签声称全部消除。

候选增强的本项目规则：先在每条原文中匹配术语词表，把所有匹配术语跨度内的字符位置标记为受保护；取两句共有的字符类型，只要某类型在任一受保护位置出现过，就从候选类型中排除。随机选 `floor(0.75 × 候选类型数 + 0.5)` 个类型，将这些类型在两句中的所有出现位置替换为 `<mask>`。这是半数向上取整，0.75作用于**字符类型**而非位置，必须同时报告实际被替换的位置比例。候选为空或增强后没有变化的样本不进入UL，并记录数量；有效无标签微批不足2对时该批UL跳过并记录。

农业术语保护词表目前**未提供**，`term_lexicon=null` 是明确阻塞项；不能凭空构造后声称是作者原词表。随机掩蔽、术语保护掩蔽的消融需匹配掩蔽数量和强度，并人工检查扰动是否明显改变标签含义。

## 2.5 半监督对照的最低实现规范

- **自训练**：先以相同L训练CE模型，使用冻结的最优第一阶段checkpoint对相同U生成一次概率，固定阈值0.95；只接收高置信伪标签，在第二阶段与L一起训练。记录接收比例、类别分布、每阶段更新和额外计算，不读取U隐藏标签。
- **一致性对照**：第一阶段同样用L训练；第二阶段将原文作为弱视图，以相同的强掩蔽规则构造增强视图，停止梯度的弱视图预测仅在置信度≥0.95时提供伪标签，对强视图计算一致性CE，建议权重0.5。明确这只是拟实现的 FixMatch-style 对照，不等同于官方实现。
- **监督Transformer**：使用各自的预训练checkpoint和tokenizer，仅用同一L微调，0.5阈值，验证集选择。模型版本和预训练知识来源另行记录。

所有对照的阶段时长上限、搜索次数和选择原则按本协议登记；实际计算量／预训练开销单列。若方法无法使用某项设置，说明原因并保留可复核的替代协议，不制造“完全等价”的假象。
